佣金结算规则

原型规则，需在正式代理协议中确认。

1
归因锁定

客户首次有效访问绑定渠道；覆盖、跨端与归因期限须明确。

2
订单确认

仅在企业支付回调或人工核实后进入“已确认”。

3
退款期管理

退款、拒付或服务取消时自动冲减待结算佣金。

4
人工/企业结算

首期导出结算单并人工复核；后续接入合规打款流程。

3

安全与接口

真实上线前必须由服务端实现。

A
角色与审计

管理员、客服、运营、财务分权；每次处理留日志。

B
支付回调验签

只在受控服务端验签、记账和更新订单。

C
上游 API 隔离

密钥仅保存于服务端，前台永不暴露。

上线分期

先确保订单与结算可审计，再接自动化能力。

A
本次第一版：界面与业务规则

前台商品选择、渠道链接规则、管理后台信息架构、订单队列和结算台账原型。

B
第二版：真实账户与数据

新公司主体、代理注册审核、数据库、访问事件、归因、订单记录、售后工单和权限。

C
第三版：支付与上游协同

完成 ICP、企业支付商户、隐私与退款条款后接入支付；天策 API 或合法授权的上游供货接口只用于履约。
