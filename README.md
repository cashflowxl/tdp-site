## 渠道与订单后台第一版

`lingdi-console.html` 是领地 AI 的内部管理后台**界面与规则原型**。它包含渠道专属链接、访问/转化漏斗、订单处理队列、佣金结算状态、产品库存、代理准入、客服工单、安全与接口边界和上线分期，用于确认业务流程与字段口径。

该页面不包含登录、数据库、支付、真实客户数据、上游采购、发货、结算或任何密钥；页面中所有渠道、订单和金额均为演示数据。正式实现需先完成新运营主体、备案/企业支付、隐私与退款规则、代理协议、服务端权限和数据库审计设计。

`lingdi-store.html` 是客户与渠道商使用的电脑端前台原型。它与后台共享同一组未来业务流程，但当前只提供前端交互演示；不会收款、创建订单、查询客户信息或发送数据给天策。

电脑端的配套页面为 `lingdi-product.html`（商品详情/下单流程演示）、`lingdi-orders.html`（订单查询演示）和 `lingdi-partner.html`（渠道申请与结算规则演示）。这些页面均为静态原型，未实现账号、提交、支付、数据库、结算或上游履约。

补充原型页面包括 `lingdi-support.html`（订单核验后售后/退款工单流程）、`lingdi-register.html`（账号注册与协议同意流程）及 `lingdi-cart.html`（购物车与服务端结算边界）。

## 领地 AI 价格更新

`lingdi-ai-pricing.js` 是领地 AI 方案卡的本地价格配置。当前页面是纯静态页面，价格不会自动或实时同步。

安全更新流程：

1. 仅从已获授权的信息源人工只读核对，不登录用户账号，不抓取页面，不调用未授权接口。
2. 更新 `lingdi-ai-pricing.js` 中的 `price` 和 `verifiedAt`。该配置不包含商品跳转、订单或支付参数。
3. 同步更新根路由 `index.html` 中的静态回退价格、页面描述、Open Graph、X 元信息、JSON-LD 与 FAQ。`lingdi-ai.html` 仅用于把旧链接兼容跳转到根路由，不承载产品内容。
4. 检查页面仍显示静态价格与库存提示，以及“支付服务待接入，当前页面不会收款或创建订单”。
5. 本地验证后，由负责人另行确认是否提交、发布。

未来如需自动同步价格或库存，只能在上游提供并明确授权只读接口、回调或共享数据源后实施。建议在构建阶段读取该数据源并生成本地价格配置与元信息，不应在访客浏览器中携带密钥、抓取上游页面或调用未授权接口。不得由该数据层创建订单、收款、采集账号数据或处理密码、验证码、Cookie、Session、令牌。

## 临时人工收款边界

根首页当前展示微信、支付宝两张临时个人收款码，由客户自行扫码并联系售后人工核对。页面不接入 SDK、API、商户号或支付密钥，不自动创建订单、确认到账或发货，也不收集姓名、手机号、账号或其他客户资料。

该流程仅为企业收款码接入前的临时过渡，不代表企业收款主体。后续只有在主体、支付服务商、商户资质、订单字段、退款/交付规则、隐私与数据保存要求均确认后，才能另行设计服务端订单与支付流程；支付密钥必须保存在受控服务端密钥系统中，不能写入静态页面或仓库。
